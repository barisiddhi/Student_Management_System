# Student_Management_System
Student Management System is a desktop application built with Java Swing and JDBC. It uses a layered architecture (UI, DAO, model) and MySQL for storage. Users can register, log in, and manage student records with create, read, update, delete, and search operations

## Features

- User Registration and Login
- Add Student Records
- Update Student Information
- Delete Student Records
- Search Students
- MySQL Database Connectivity
- Java Swing GUI

---

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
